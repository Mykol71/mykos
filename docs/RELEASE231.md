# MYKOS release231

Receiver adds engraved brushed-aluminum component bases, a wood cabinet, compact time controls, amber time labels, red source lamps and live high-range VU indicators. The theme remains limited to its existing authorized user. Other themes retain their presentation.

The new `sudo mykos-who` command reports unexpired browser logins without revealing tokens or credentials; it does not verify live presence.

Business backup account management is supplied only by a separately installed private extension. Core updates preserve existing backup data.

Existing platform support limits remain unchanged. This release does not restore EL8 host support. Protected repositories retain LAN restrictions.

The updater retains its original Azure backend as the default while preserving safe directory-link parsing and failed-download/HTML-response rejection. An explicit operator backend override remains available.
